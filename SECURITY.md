# Política de seguridad

## Versiones compatibles

| Versión | Soporte de seguridad |
| --- | --- |
| 1.0.x piloto | Sí |
| Versiones anteriores | No |

## Reportar una vulnerabilidad

No publiques vulnerabilidades, credenciales, datos académicos ni información personal mediante una incidencia pública.

Utilizá preferentemente los informes privados de vulnerabilidad de GitHub:

https://github.com/javiyjdr-byte/asistente-universitario-web/security/advisories/new

Como alternativa, podés escribir a:

eduasistenteba@gmail.com

Incluí una descripción clara, los pasos necesarios para reproducir el problema, el impacto posible y las páginas afectadas. No incluyas secretos ni datos reales de estudiantes.

## Alcance

Esta política comprende el sitio público, sus enlaces y su interacción con el portal del Asistente Universitario. El backend, las credenciales y los datos académicos no forman parte de este repositorio público.

## Divulgación responsable

No intentes acceder, modificar o eliminar datos de otras personas. No realices pruebas de denegación de servicio, ingeniería social ni acciones que interrumpan el piloto.
